## 🎯 À propos

Ce projet explore les **effets du changement climatique** en Afrique à travers une analyse visuelle approfondie des températures quotidiennes sur **43 ans** (1980-2023). L'objectif est d'identifier les tendances du réchauffement climatique et de sensibiliser aux enjeux environnementaux du continent africain.

### 🌟 Objectifs

| Objectif | Description |
|----------|-------------|
| 📊 **Visualiser** | Évolution des températures moyennes par pays |
| 🔍 **Comparer** | Distributions thermiques avant/après 2000 |
| 📈 **Identifier** | Tendances du réchauffement climatique |
| 💡 **Sensibiliser** | Impact du climat sur le développement africain |

## 📊 Dataset

| Caractéristique | Valeur |
|----------------|--------|
| 📅 **Période** | 1980 - 2023 (43 ans) |
| 📏 **Observations** | 464,815 enregistrements quotidiens |
| 🌍 **Pays** | 5 pays d'Afrique |
| 🌡️ **Variables** | DATE, PRCP, TAVG, TMAX, TMIN, COUNTRY |
| 💾 **Taille** | 18.5 MB |

### 📋 Variables du dataset

- **DATE** : Date de l'observation (format: YYYYMMDD)
- **PRCP** : Précipitations (pouces)
- **TAVG** : Température moyenne (°F)
- **TMAX** : Température maximale (°F)
- **TMIN** : Température minimale (°F)
- **COUNTRY** : Pays

## 📈 Résultats clés

### 🔥 Augmentation de température (Avant 2000 vs Après 2000)

| 🏆 Rang | Pays | Avant 2000 | Après 2000 | Augmentation |
|---------|------|------------|------------|--------------|
| 🥇 | **Cameroun** | 78.85°F | 81.48°F | **+2.63°F** 🔥 |
| 🥈 | **Angola** | 74.26°F | 75.94°F | **+1.69°F** |
| 🥉 | **Tunisie** | 66.81°F | 68.52°F | **+1.71°F** |
| 4️⃣ | **Égypte** | 73.16°F | 74.22°F | **+1.06°F** |
| 5️⃣ | **Sénégal** | 82.72°F | 83.17°F | **+0.45°F** |

<div align="center">

**📊 Moyenne globale : +1.51°F sur l'ensemble des pays**

## 🚀 Installation

### 📋 Prérequis

- Python 3.12+
- pip
- Jupyter Notebook ou JupyterLab

### ⚡ Installation rapide
```bash
# 1️⃣ Cloner le repository
git clone https://github.com/chniang/Africa_climate_change_visualisation.git
cd Africa_climate_change_visualisation

# 2️⃣ Installer les dépendances
pip install pandas numpy matplotlib seaborn plotly jupyter

# 3️⃣ Lancer Jupyter
jupyter notebook climate_analysis.ipynb
```
